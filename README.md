# ProfitIQS — Video Asset Repo

Source files for building ProfitIQS VSL / promo video content. Not the website repo
(that's `profitiqsv2`) — this is just the raw deliverables and affiliate material,
organized for pulling into Claude Desktop or any video tool.

**Brand:** ProfitIQS · 63 real business intelligence systems across 21 industries,
sold through Digistore24. Essential / Elite / Complete tiers, $97 / $197 / $249.

## Folders

### `Complete-Products/` — 21 files
The real, final, customer-facing Complete-tier deliverable for each of the 21
industries (both Essential and Elite workbooks bundled, plus the Field Guide and
Quick Start). These are the actual files a buyer receives — straight from the
verified CLEAN release folder, not a draft or earlier version.

### `Affiliate-Kits/` — 22 files
The full real affiliate marketing kit: one zip per industry (21) plus
`ProfitIQS-Master-Affiliate-Kit.zip` (commission schedule, compliance guide, brand
assets). Each niche kit has real buyer profiles, pain points, hooks, objection
handling, and compliance-checked copy — the same kits live on the site at
`/affiliates`.
